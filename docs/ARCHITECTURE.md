# Scalia HR — Architecture Decisions

> SaaS B2B HCM multi-tenant, modular clone of SAP SuccessFactors.
> Stack: Next.js 15 (App Router) + Supabase + Prisma (client-only).

---

## D1 — Single Source of Schema

**Decision:** `supabase/migrations/` (raw SQL) is the **only** source of truth
for the database schema. Prisma is used exclusively as a type-generation client
via `npm run db:sync` (`prisma db pull && prisma generate`).

**Rationale:** Supabase RLS policies, custom functions (`requesting_tenant_id`,
`is_tenant_admin`, `custom_access_token_hook`), FORCE ROW LEVEL SECURITY, enum
types, and GRANTs cannot be expressed in Prisma's migration DSL. Maintaining two
migration chains (Prisma + SQL) creates drift and security gaps.

**Rules:**
- `prisma migrate` and `prisma db push` are **prohibited**.
- `prisma/migrations/` directory must not exist.
- `schema.prisma` uses `@@map`/`@map` only as generated by `db pull`.
- Every business table has `tenant_id uuid NOT NULL` with a FK to `tenants(id)`.

---

## D2 — Tenant in the JWT

**Decision:** The active tenant is injected into the Supabase JWT via a
`custom_access_token_hook`. RLS policies read it with
`public.current_tenant_id()`.

**Tables:**
- `user_tenant_memberships` — maps users to tenants with `app_role` and
  `is_active` flag. Composite PK `(user_id, tenant_id)`.
- `user_settings` — stores `active_tenant_id` per user.

**Hook:** `public.custom_access_token_hook(event jsonb)` (SECURITY DEFINER,
`search_path = ''`) adds `tenant_id` and `app_role` claims from the active
membership. Only `supabase_auth_admin` can execute it.

**Client:**
- `switchTenant(tenantId)` Server Action validates membership (Zod + DB),
  updates `active_tenant_id`, refreshes session.
- `revokeMembership` deactivates the membership and signs out the user globally.

## D3 — Prisma Without RLS Bypass

**Decision:** The Prisma connection uses a custom PostgreSQL role `prisma_app`
with `NOBYPASSRLS`. Every query runs inside a `$transaction` that first sets
`role authenticated` and injects JWT claims via `set_config`.

**Implementation:**
- `lib/db/tenant-client.ts` — sets `request.jwt.claims` per operation.
- `lib/db/admin-client.ts` — privileged connection, importable only from
  `lib/jobs/` and `lib/admin/`.
- ESLint `no-restricted-imports` enforces boundaries.

---

## D4 — Secrets & Network Hardening

**Rules:**
- All secrets read from `.env` (never committed). `.env.example` has
  placeholders only.
- Docker services publish ports on `127.0.0.1` only.
- `check:forbidden` script fails on `"service_role"`, `"bitnami"`, or
  `"MOODLE_WS_TOKEN"` in client code (server-only files allowlisted).
- Pre-commit hook (husky + lint-staged) runs `check:forbidden` + lint.

## D5 — LMS Integration (Moodle)

**Decision:** Moodle (`moodlehq/moodle-php-apache`) runs as a sidecar service
alongside the application stack. Scalia HR communicates with it exclusively via
REST web services, using a single service token (`MOODLE_WS_TOKEN`) stored
server-side.

**SSO:** `auth_userkey` plugin, mapping by `username` = Supabase user UUID.
The `/lms/launch` route auto-provisions the Moodle user on first access and
redirects via `auth_userkey_request_login_url`.

**Tenant Isolation:**
- Each tenant gets its own Moodle **category** (courses) and **cohort**
  (employees), stored in `lms_tenant_map`.
- `lms_user_map` associates each Supabase user with their Moodle user ID.
- Both tables have RLS ENABLED + FORCED, scoped by JWT `tenant_id`.

**Sync (`lib/jobs/lms-sync.ts`):**
- ACTIVE + unmapped → create Moodle user, add to cohort, store mapping.
- TERMINATED + mapped → suspend in Moodle.
- `is_anonymized` + mapped → suspend + anonymize (ARCO: firstname=Usuario,
  lastname=Anonimizado, email=`anon_{id}@scalia.local`).
- ACTIVE + mapped → unsuspend (rehire).

**Security:**
- `moodle-client.ts` has a `typeof window !== "undefined"` server-only guard.
- `MOODLE_WS_TOKEN` is in the `check:forbidden` list.
- Server-only files (moodle-client, provision-tenant, lms-sync) are allowlisted.
- Moodle Docker service binds only to `127.0.0.1`.
